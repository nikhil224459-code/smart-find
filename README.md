# 🔍 Smart Find

A web-based platform designed to help people report and find lost items and missing persons.

## ✨ Features

- Report lost and found items
- Report missing persons
- Admin verification system
- Police Admin and NGO Admin roles
- Case status tracking
- Image and text-based matching
