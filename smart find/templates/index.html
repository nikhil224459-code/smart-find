HOW IT WORKS

📋

01 - Submit Report

Users register lost items or missing persons with full details, descriptions, dates, locations, and photograph uploads.

🔍

02 - Text Matching

System compares description, category, and location fields against all existing records using weighted similarity engine.

📷

03 - Image Matching

OpenCV compares uploaded item photos using histogram and feature matching to find visual similarities.

🧑

04 - Face Recognition

AI face recognition compares missing person photos to identify potential matches automatically.

🛡️

05 - Police Verification

Police Admin reviews suggestions, confirms or rejects matches, and officially closes resolved cases.

🤝

06 - NGO Coordination

NGO Admins access verified active cases and provide coordination support and community outreach.
